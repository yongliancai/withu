# 伴旅 WithU — AI 伴侶 PWA 測試版

依《AI 伴侶 App 成果報告書（新版產品規格）》製作的網頁版 App（PWA）測試版：**不分級、不含親密層**。手機瀏覽器打開、可加入主畫面、可收推播。

App 名稱「伴旅 WithU」出現在 `public/index.html`、`public/manifest.webmanifest`、歡迎頁（`public/app.js`）和分享圖卡。

---

## 部署（Hostinger VPS＋CloudPanel）

目前的部署：CloudPanel 的 Node.js 網站 `liancai.fun`（站台使用者 `liancai`，App Port 5001），程式在 `/home/liancai/htdocs/liancai.fun`，用 pm2 執行（名稱 `companion`），程式碼放在 GitHub `yongliancai/withu`。

**更新到最新版**（用 root 登入後）
```bash
su - liancai
cd ~/htdocs/liancai.fun && ./deploy.sh
```
`deploy.sh` 會抓 GitHub 最新版、套件有變才重裝、再重啟 App。`data/`（資料庫、照片、語音）和 `.env` 不在版本管理裡，更新不會動到。備份只要備份 `data/`。

**`.env` 改了之後**：`pm2 restart companion`。

**第一次接上 GitHub**（已做過就跳過）：在主機產生部署金鑰並加到 repo 的 Deploy keys，然後在網站資料夾執行 `git init`、`git remote add origin git@github.com:yongliancai/withu.git`、`git fetch origin`、`git checkout -f -B main origin/main`、`git branch -u origin/main`、`npm install --omit=dev`、`pm2 restart companion`。

**推播金鑰**：`npm run vapid`，把印出的兩把金鑰貼進 `.env` 再重啟。

**寫實照片**：不用設定也會自動從 Openverse（免費、可商用的 CC 授權照片）補照片，照片下載存在主機上並標示攝影者。想要更多來源：到 https://pixabay.com/api/docs/ 登入後拿免費金鑰，貼進 `.env` 的 `PIXABAY_API_KEY`。Pexels 從 2026 年 10 月起暫停發新金鑰。後台「照片庫」也可以自己上傳，或按「AI 生成缺少的照片」（OpenAI 圖片模型，每張約 NT$0.2，只生成沒有人的風景與物件）。

**十人試聊報告**（用主機的金鑰讓 10 位測試使用者自動聊天，金鑰不會離開主機；用暫時的資料夾跑，不會動到正式資料；一次約 NT$20–60）：
```bash
cd ~/htdocs/liancai.fun && node scripts/persona-test.js        # 全部 10 位
node scripts/persona-test.js F1 M4                              # 只跑其中幾位
```
報告會存在 `reports/persona-日期.md`（不會進 GitHub），把檔案傳給 Claude 看。

**費用上限**：每人每天角色最多回 150 次、看 20 張照片（`.env` 的 `DAILY_REPLY_CAP`、`DAILY_PHOTO_CAP` 可調）。超過時角色會自然地說要休息、明天再聊；危機訊息不受限制。

**安全設定與備份**：見 `docs/security.md`（後台 IP 白名單、SSH、防火牆、每日備份、還原方式）。

**隱私權政策**：`https://你的網域/privacy`（申請 Uber API 時需要）。個資外洩應變流程在 `docs/incident-response.md`。

另有 Dockerfile／docker-compose 可用在其他主機，本專案目前沒有使用。

## 給測試者

1. 用手機打開網址，輸入邀請碼。`.env` 的 `INVITE_CODES_F` 是女性向群組、`INVITE_CODES_M` 是男性向群組；註冊時可以選自己的性別和想遇見誰。
2. **iPhone**：Safari → 分享 → 加入主畫面，**從主畫面打開**後到「我 → 通知」開啟，才收得到他的訊息。Android Chrome 會直接提示安裝。
3. 每個人註冊後會拿到一組**登入碼**，換手機時用它回來。

## 後台

`https://你的網域/admin`，輸入 `ADMIN_TOKEN`。分頁：

- **費用**：今天、這個月花了多少（美元與約台幣）、最近 30 天每日花費、花在哪些用途、花最多的使用者。花費快到預算或超過時，每一頁上方都會提醒。
- **系統設定 → AI 功能檢查**：聊天、語音合成、語音辨識、圖片生成各試一次（約 NT$1），角色照片或語音通話沒反應時先按這個，失敗會顯示原因。
- **系統設定**：不用改程式、存檔立刻生效。動態（每天幾則、間隔、發文機率）、每日上限、關係節奏、主動訊息頻率、貼圖間隔、同時認識幾個角色、記憶整理頻率、預算（每日／每月上限、提醒門檻、超過時是否暫停）。超過預算且設定暫停時，角色不再回覆和主動傳訊息，App 會顯示「伴旅暫時休息中」；危機訊息照常回。
- **公告**：發在 App「聊天」頁上方，可勾選同時推播給所有人；可下架。
- **官方角色**：修改現有角色、新增角色（立即出現在探索）、上架／下架。
- **角色照片**：每個角色一張寫實 AI 主照＋6 張生活照（每張約 NT$2）。可以一次幫所有角色生成主照、補齊生活照，或單獨重做、隱藏某一張。自己捏的角色建立時會自動生成主照；任何角色變曖昧時，缺的生活照會自動補上。每個角色的臉部特徵（臉型、眼睛、鼻子、小特徵）會挑沒人用過的組合，避免撞臉。
- **測試者 → 詳細**：今天的用量、這個月的花費、認識的角色和關係進度（不顯示聊天內容和記憶，只顯示數量）；可以重置今天的用量、代為刪除帳號與所有資料。按「看角色的生活」可以看角色的生活日誌、每月大事記、生活連續劇（可提前結束）、發過的動態（可刪除）。
- **數據**：可切換全部／女性向／男性向。D1、D7、D30 留存，每人每天訊息數、主動訊息、語音、tokens、生活事件（照片、訂餐、出遊）、成本與月推估，角色被認識次數，「即將推出」的願付金額。
- **邀請碼**：新增或停用邀請碼，立即生效、不用重啟；看每組邀請碼有幾人註冊。`.env` 裡的邀請碼也會列出（唯讀）。
- **測試者**：停用帳號（立即登出所有裝置，角色不再主動傳訊息，資料保留），或幫忘記登入碼的人重新產生一組。
- **角色廣場**：看使用者分享的角色和檢舉原因，手動下架或恢復。
- **流行新品**：陪吃飯推薦新品時只會從這份清單挑；每筆附官方來源與到期日。
- **意見回饋**：測試者在「我 → 意見回饋」寫的內容。
- **危機事件**：只列出時間、測試者、角色，不顯示對話內容；你私下關心後可以留下處理紀錄。
- **系統紀錄**：系統自己處理不了的問題，保留 30 天，可依等級、來源、處理狀態篩選，處理完按「標記已處理」並寫下怎麼處理的。
  - 錯誤：AI 呼叫失敗、回傳格式不對、語音轉文字失敗、伺服器例外、手機端的程式錯誤
  - 警告：語音合成失敗改傳文字、推播送不出去、角色回了空訊息、相遇情境被擋下（附原文，方便判斷是不是擋錯了）
  - 使用者回報：測試者在聊天室右上角「⋯ → 回報問題」寫的內容；勾選「附上最近的對話」才會附最近 16 則訊息
  - 同樣的錯誤一分鐘內只記一次；API 金鑰、登入碼等不會被記錄

### 自己寫的相遇情境
一般的戲劇衝突可以使用（英雄救美、被小混混找麻煩、打架受傷、車禍、生病住院）。只擋：性內容、未成年、真實人物或現有作品角色、血腥細節、奇幻／非人類設定。被擋下時會說明哪一點不行，並給一個改寫版本，可以一鍵套用或自己修改（原本寫的內容會保留）。

### 解決句點
- **回覆方向**：角色每次說完話，輸入框上方出現 3 個方向（例如「😂 吐槽他」「❓ 問後來呢」「🙋 說說我自己」），點了會幫你寫好一句放進輸入框，可以修改再送。可在「我 → 顯示回覆方向」關掉。
- **話題錦囊**（聊天室左下角 ✦）：「他帶我聊」、問他一件事、小遊戲（二選一、真心話、猜猜看、故事接龍）、一起做點什麼、分享照片。
- **角色主動帶話題**：對方連續回很短（嗯、哈哈、好）時，角色不再追問，改成分享一件事或提議小遊戲。
- 第一次相遇時角色會留一個好回答的小問題。

### 說話風格（後台可改）
角色依「年齡（20–24／25–29／30 以上）× 性別」套用一包說話風格：傳訊息的習慣加示範對話，再由個性原型微調。所有角色都避免單獨回「喔」「嗯」「哈哈」「笑死」這類容易句點人的字，並用台灣用語。後台「說話風格」分頁可以直接修改，立即生效。共同規則也禁止「我接住你了」「你不是一個人」這類罐頭安慰，開場先對當下反應、不急著自我介紹。

### 語感調校（使用者回饋）
- 使用者長按角色的話可以評「很像真人／怪怪的」並寫「他應該怎麼說」；在聊天裡說「什麼意思？」「聽不懂」也會記下角色的前一句。**只有勾選同意的人才收**（註冊時可勾、「我 → 隱私與資料」可開關），存之前去掉暱稱、稱呼、email、電話、網址。
- 「怪怪的」會立刻讓那個角色少用那種說法。
- 後台「語感調校」審核：寫上自然的說法 → 存成示範，同年齡性別（可選同個性）的角色回話時立刻參考。累積夠多可以下載 JSONL 訓練檔拿去微調模型。

### 使用說明與更新介紹
- 新使用者第一次到「聊天」時，吉祥物會一步一步帶著看五個分頁（圈出位置＋說明，可以上一步、略過）；第一次進聊天室時再介紹裡面的按鈕。
- 每次更新有新功能時，在 `public/app.js` 最上面的 `WHATS_NEW` 加一筆（日期＋幾項說明，可以指定要圈哪個按鈕）；使用者下次打開會看到一次。
- 「我 → 設定」可以再看一次使用說明和更新內容。

### 角色照片怎麼解鎖
主照是精緻插畫（二次元角色是動畫風），生活照是寫實但不露臉的手機照片，都是 AI 生成的虛構人物；照片上不另外標示，改在使用說明和隱私權政策告知。只有需要標示作者的 CC 授權圖庫照片會在角落註明。後台「角色照片」可以一鍵把舊照片換成新畫風。自己捏的角色可以選臉型、眼睛、氣質（選填，沒選的由系統隨機、避免撞臉），只會影響照片插畫；不開放上傳真人照片。模糊版本由伺服器先做好，還不能看的照片，手機拿到的就只有模糊圖。

| 關係 | 看得到 |
|---|---|
| 還沒認識（探索） | 很模糊的主照 |
| 認識 | 有點模糊的主照 |
| 朋友 | 清楚的主照（個人頁大頭照也會換成照片） |
| 曖昧 | 3 張生活照 |
| 交往 | 再 2 張 |
| 付費限定 | 1 張，測試期顯示「付費解鎖・即將推出」並記錄願付價格（後台「數據」） |

### 自動回報與修正程式問題
手機端錯誤、伺服器 500、功能檢查沒過（畫面出現 null、圖片載不出來）都會記到後台「系統紀錄」，每小時歸類成「待修清單」；設定 `GITHUB_REPO`＋`GITHUB_ISSUES_TOKEN` 後自動開成 GitHub Issue，再由排程任務開修正 PR，你確認後部署。見 `docs/auto-fix.md`。

### 心情按鈕
26 種心情分成累、低落、不安、生氣、開心、想念（親暱的要關係到了才出現）；可以自己寫心情，常用的會留下來。
「**說不出來**」給不知道自己是什麼感覺的人：① 身體哪裡有感覺 ② 強度和想躲起來還是想做點什麼 ③ 從候選的情緒詞挑最像的（都不像也可以）。角色不會直接下結論，而是用問句幫對方把感覺說出來，再問一個好回答的問題幫忙分辨。只記錄選了哪一步、強度，不記錄內容，方便之後研究使用情形。

### 語音通話
聊天室右上角的電話。輪流講話：你說完按一下，角色聽完用他的聲音回你（約 2–4 秒）。曖昧以後才能打，每人每天 10 分鐘（後台「系統設定 → 語音通話」可調）。他在睡覺或上班時會沒接。通話內容會留在聊天室（語音訊息），結束時有一張「通話 幾分幾秒」的紀錄。

### 角色的生活日誌
每個角色每天早上在背景寫好當天的安排（符合他的班表、天氣、節日、連續劇），聊天、發動態都照這份日誌，所以說的和發的一致；每個月整理成大事記，開新的生活事件前會先看過，不會繞回來重做。只替最近 7 天有來的人寫，每個角色每天一次便宜的模型呼叫。

### 記憶整理與標籤
每聊幾輪（後台可調）整理一次：記下之後還用得到的事、刪掉只是當下狀態的，每條記憶和聊天片段都有主題標籤（工作、作息、心情、計畫……）。對方說話時先依主題找相關的記憶；聊天室「搜尋」也可以依主題找聊過的事。

### 不重複
- 他講過的自己的生活故事會被記下來，之後只能延續或說新進展，不會重講。
- 每聊 30 則會把較早的對話整理成摘要，讓他記得比最近 30 則更久以前的事。
- 新回覆和他最近說過的話太像時，會自動重寫一次，並在「系統紀錄」留一筆警告。

## 流行新品清單

陪吃飯推薦的「新品」只會從 `data/trends.json` 挑，避免模型編造。格式見 `trends.example.json`，每筆附官方來源網址與到期日；過期自動不用。改完不用重啟。

```bash
cp trends.example.json data/trends.json && nano data/trends.json
```

### 一起做點什麼與明信片

- 散步已移除。改成聊天室左下角的「話題錦囊」裡的「一起做點什麼」：一起看劇、陪你專心 25 分鐘（時間到他會來問進度）、睡前聊聊、一起吃飯。聊天中說好要一起看也會自動開始。
- 你傳很美的風景照時，他偶爾會做成明信片（一天最多一張），收進「我們的故事」。
- 他每週休假的下午會寄一張風景明信片給你。
- 角色都生活在現實的台灣：非人類、奇幻、異世界的情境會被婉拒。

### 上線狀態與回覆節奏

- 聊天室上方顯示他的狀態：🟢 上線中、🟡 上班中、⚪ 最後上線…、🌙 睡覺中，依他的作息自動切換。心情句改放在他的個人頁。
- 他在線上時：先「已讀」，1–4 秒後開始打字，每秒大約 5 個字，每則最多 8 秒，兩則之間停一下。
- 他在忙或睡覺時：真的晚點才回（上班中 1–8 分鐘、離線 1–3 分鐘、睡覺就等他起床，最晚早上 9 點），回的時候會說「剛剛在忙」「剛起床」，並推播通知。對方有危機訊號時一律馬上回。
- 測試者可以在「我 → 忙的時候晚點回」關掉延遲。

### 通知

- 第一次聊完會問要不要開通知；iPhone 會先教「加入主畫面」（iOS 只有從主畫面打開才收得到）。
- 同一個人連續傳好幾則，只會更新成一則「3 則新訊息」；App 圖示和「聊天」分頁會顯示未讀數字；你的勿擾時段通知不會響。
- 推播需要先在 `.env` 設定 VAPID 金鑰：`npm run vapid` 產生後貼進 `.env`，再 `pm2 restart companion`。

### 角色怎麼被形塑

不是訓練模型，而是每次對話都把角色設定寫進提示詞：

| 層 | 內容 | 什麼時候更新 |
|---|---|---|
| 核心人設 | 職業、原型、價值觀、口頭禪、生活中正在進行的事 | 建立時決定；官方角色可在後台「官方角色」調整 |
| 長出來的個性 | 幽默感、說話節奏 | 認識、朋友期每 15 則訊息，依對方的反應（回得長、笑了、延續話題／冷淡、明確不喜歡）整理；曖昧後鎖定 |
| 偏好 | 對方喜歡／不喜歡的說法（多一點、少一點） | 鎖定後仍每 30 則更新 |
| 相處習慣 | 對方明確要求的事（「別一直問我吃了沒」） | 說出口就記下，一直有效，優先於其他規則 |
| 記憶 | 喜好、作息、重要的事 | 每則訊息 |

每週到後台「數據」看本週摘要與「大家最常要求的相處習慣」，調整的是官方角色與整體規則，不改個別使用者的角色。

### 訊息跟現實時間對齊

- 他看得到現在的時段（早上、中午、深夜…）和「距離上一則訊息過了多久」；對話中隔很久的地方會標上時間。
- **發送前檢查**：主動訊息和晚回的訊息送出前，會先對照現在的時間和最近 14 則聊天紀錄。說法跟時間對不上（下午說早安、晚上問午餐）、接不上前面的對話、對方剛說在忙還硬開話題，就自動改寫或取消。改寫和取消都記在後台「系統紀錄」（來源 review）。
- 他睡覺時不會主動傳訊息；你們正在聊、或他上一個問題你還沒回時，不插入新話題。

### 他生活裡的連續劇

每個角色會依自己的職業、個性和「生活中正在進行的事」，遇到一件接下來 3–6 天的事（例如咖啡師參加拉花比賽、研究生等審查結果），他有空時每天推進一段、發成動態或限時動態，最後有結果（不一定是好結果）。他在聊天裡只知道已經發生的部分，不會劇透。想跟你說的時候會私下傳訊息（慢熱、獨立的角色常常不說）。一件事結束後休息兩天才會有下一件；剛認識的前兩天不會有。

### 同一個世界：住哪裡、天氣、節日

- 每個角色住在台灣的某一區（例如台北市中山區），也有自己的生日。
- 你住哪裡，他只從聊天得知（例如你說「我在新竹上班」）；不知道時他會自然地問，不會假設。
- 他看得到他那邊和你那邊的真實天氣（Open-Meteo，免費、不用金鑰），以及這幾天的國定假日和節日（依人事行政總處 115、116 年行事曆）。用自己的生活經驗自然帶到，不像氣象播報。

### 自動更新

App 每 5 分鐘、以及每次回到 App 時會檢查有沒有新版本（用 GitHub 的版本號），有的話上方出現「伴旅有新版本了・更新」；離開超過 10 分鐘再回來、而且沒在打字時，會直接更新。

### 系統主題與吉祥物

設定裡可以選三種系統主題，各有一隻原創吉祥物：奶茶（小糰，麻糬）、夜空（小月，抱著月亮的夜貓子）、森林（小芽，頭上長出嫩葉的種子）。心情按鈕和聊天室上方的按鈕會跟著主題換成那隻吉祥物。

### 相處偏好（跨角色）

系統會從你和所有角色的相處，整理出你喜歡的聊天方式（例如「喜歡對方先分享自己的事」「不喜歡一直被問問題」），之後認識的新角色一開始就用這個方式跟你相處。只記說話與相處方式，不記任何私事；角色之間仍然只知道你親口跟他說的事，關係進度也不會因此變快。可以在設定的「隱私與資料」查看或清除。

### 心情按鈕

聊天列表右下角、聊天室上方的吉祥物按鈕。不想打字時，選一個心情（壓力好大、好累、好無聊……；「想你」「想要抱抱」要到曖昧才會出現，「想撒嬌」「想見你」要交往後才有），連按越多下代表越強烈，會有表情飛出來的特效。他會看到，依自己的個性和你們的關係回應；他在忙或睡覺時一樣晚點回。

### 一起出門的小插曲、一起完成的小目標

- 出遊模式中，他偶爾會遇到小插曲讓你選（例如走老街還是去河堤），選擇會留在回憶錄。
- 你在聊天中提到想改掉的小習慣（想早點睡、想多喝水），他可能會提議一起完成一個 5–10 天的小目標。在記事本打勾，不用連續，做不到也不會被責備；隔天晚上他會輕鬆地問一下。

### 紀念日

「我們的故事」最上面列出接下來的紀念日：認識 100 天、交往紀念日、他的生日、你的生日（從聊天得知）。前一天和當天聊天列表會有小提醒，當天他也會用自己的方式提起。

### 角色池

- 探索頁最上面可以直接「自己捏一個」。
- 26 位官方角色，分成「日常溫暖、夢幻系、青春回憶、職場、異國、二次元」六類，探索和「我想認識他」都可以用分類篩選。
- 原型參考：乙女遊戲調查中最受歡迎的「成熟體貼、溫柔、外冷內熱、傲嬌」，國內女性向手遊常見的總裁、年下、竹馬、設計師、醫生、撩人系；男性向常見的青梅竹馬、學妹、大姊姊、辣妹、天然呆、女主管，以及「最想娶的職業」調查前段的護理師、藥師、幼教老師。
- 青梅竹馬、鄰家哥哥這類角色一開始就是朋友，並帶有共同過去的設定記憶。

### 相遇入口

- **我想認識他**（先選人）、**來場偶遇吧**（先選情境；可以拍一張現在的地方，AI 判斷是哪種情境，照片不保存）、**依心情認識**（低落、好累、焦慮、無聊、開心想分享，推薦適合此刻的人）。
- 心情低落時遇到的人，前三天只會是朋友：先陪伴、幫你把感受說清楚，不曖昧。

### 我的主頁（像 IG）

底部「我」是你自己的主頁：大頭貼、簡介、你發過的動態，還有「狀態」（例如 😴 好累、💼 忙碌中，24 小時後自動消失）。你認識的人看得到你的狀態，會依此關心你。設定移到右上角的齒輪。

### 你也可以發動態

在「動態」或「我」按「＋ 發動態」，可以發一般動態或 24 小時的限時動態，選擇誰看得到（所有人、只給戀人、指定的人）。他們看到後會依關係和自己的作息按讚、留言，或私下傳訊息關心（私訊一樣經過發送前檢查）。

### 限時動態

「動態」頁最上面一排圓圈：還沒看過的有彩色外圈。點進去全螢幕播放，可以直接回覆，回覆會帶著那則限動傳到聊天室。

### 動態牆

底部第二個分頁。你認識的人會在午休、下班後、休假午後自己發動態（文字＋寫實照片，一天最多兩則），可以按讚、留言，他會依自己的狀態晚一點回你的留言。發動態不會推播。

### 聊天室（像 LINE）

- 右上角選單：相簿、記事本、回憶錄、搜尋、主題、個人頁、設定、回報問題。
- **記事本**：你們的約定與清單。聊天中說好「下次一起去吃豆花」，他會自己記上去；你也可以自己新增、打勾、刪除。（他的記憶仍然不公開，記事本只放約定。）
- **貼圖**：原創的「小糰」貼圖 16 張，你可以傳，他偶爾也會回貼圖。
- **主題**：預設、夜晚、咖啡廳、海邊、櫻花、森林，每個聊天室分開設定。

### 回憶錄

「我們的故事」裡的回憶錄分章節，只顯示你們已經開始的章節；還沒走到的章節連名字都不會出現，章節內還沒發生的回憶只顯示半透明的「？？」，不會劇透。模型自己記下的特別時刻收在「只屬於你們的」。

## 本機開發

```bash
npm install
npm run dev        # 不需要 OpenAI 金鑰，回覆是範例文字，可以走完所有流程
```
想看真實回覆：`OPENAI_API_KEY=sk-... STAGE_SPEED=4 node server/index.js`，`STAGE_SPEED` 讓關係推進加快，方便示範。

### 程式結構

```
server/
  index.js       API 路由、登入、上傳、靜態檔
  engine.js      對話編排層：組提示 → 呼叫模型 → 套用結果（記憶、關係、卡片、出遊…）
  prompt.js      角色規則、人設、當下情境、結構化輸出 schema
  scheduler.js   主動排程引擎（每分鐘）
  meet.js        相遇流程、情境結構化、角色分享
  memory.js      記憶挑選與權重
  ordering.js    下單轉接層、流行新品清單
  safety.js      危機偵測與求助資源
  characters.js  職業作息、角色原型、官方角色、情境
  admin.js       測試數據
public/          PWA 前端（無需打包）
```
