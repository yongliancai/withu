# 伴旅 WithU — AI 伴侶 PWA 測試版

依《AI 伴侶 App 成果報告書（新版產品規格）》製作的網頁版 App（PWA）測試版：**不分級、不含親密層**。手機瀏覽器打開、可加入主畫面、可收推播。

App 名稱「伴旅 WithU」出現在 `public/index.html`、`public/manifest.webmanifest`、歡迎頁（`public/app.js`）和分享圖卡。

---

## 部署到 Hostinger VPS

需要：一台 Ubuntu VPS、一個網域（PWA 推播、麥克風、相機都必須 HTTPS）。

**1. 網域指向 VPS**
在網域 DNS 新增 A 記錄，例如 `app.你的網域.com` → VPS 的 IP。

**2. 安裝 Docker（VPS 上只做一次）**
```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER   # 之後重新登入
```

**3. 上傳專案並設定**
```bash
# 把整個資料夾傳到 VPS，例如 scp -r companion user@VPS_IP:~/
cd ~/companion
cp .env.example .env
nano .env            # 填 DOMAIN、PUBLIC_URL、OPENAI_API_KEY、INVITE_CODES、ADMIN_TOKEN
mkdir -p data && sudo chown 1000:1000 data
```

**4. 產生推播金鑰，貼回 `.env`**
```bash
docker compose build
docker compose run --rm app node scripts/gen-vapid.js
```

**5. 啟動**
```bash
docker compose up -d
docker compose logs -f app     # 看到 companion listening on :3000 就好了
```
Caddy 會自動申請 HTTPS 憑證。打開 `https://你的網域` 就能用。

**更新程式**：傳上新檔案後 `docker compose up -d --build`。資料都在 `data/`（SQLite、照片、語音），備份這個資料夾即可。

Hostinger 若有開防火牆，記得放行 80、443。

## 給測試者

1. 用手機打開網址，輸入邀請碼。`.env` 的 `INVITE_CODES_F` 是女性向群組、`INVITE_CODES_M` 是男性向群組；註冊時可以選自己的性別和想遇見誰。
2. **iPhone**：Safari → 分享 → 加入主畫面，**從主畫面打開**後到「我 → 通知」開啟，才收得到他的訊息。Android Chrome 會直接提示安裝。
3. 每個人註冊後會拿到一組**登入碼**，換手機時用它回來。

## 後台

`https://你的網域/admin`，輸入 `ADMIN_TOKEN`。分成十個分頁（含「官方角色」與「說話風格」）：

- **數據**：可切換全部／女性向／男性向。D1、D7、D30 留存，每人每天訊息數、主動訊息、語音、tokens、生活事件（照片、訂餐、出遊）、成本與月推估，角色被認識次數，「即將推出」的願付金額。
- **邀請碼**：新增或停用邀請碼，立即生效、不用重啟；看每組邀請碼有幾人註冊。`.env` 裡的邀請碼也會列出（唯讀）。
- **測試者**：停用帳號（立即登出所有裝置，角色不再主動傳訊息，資料保留），或幫忘記登入碼的人重新產生一組。
- **角色廣場**：看使用者分享的角色和檢舉原因，手動下架或恢復。
- **流行新品**：陪吃飯推薦新品時只會從這份清單挑；每筆附官方來源與到期日。
- **意見回饋**：測試者在「我 → 意見回饋」寫的內容。
- **危機事件**：只列出時間、測試者、角色，不顯示對話內容；你私下關心後可以留下處理紀錄。
- **系統紀錄**：系統自己處理不了的問題，保留 30 天，可依等級、來源、處理狀態篩選，處理完按「標記已處理」並寫下怎麼處理的。
  - 錯誤：AI 呼叫失敗、回傳格式不對、語音轉文字失敗、伺服器例外、手機端的程式錯誤
  - 警告：語音合成失敗改傳文字、推播送不出去、角色回了空訊息、相遇情境被擋下（附原文，方便判斷是不是擋錯了）
  - 使用者回報：測試者在聊天室右上角「⋯ → 回報問題」寫的內容；勾選「附上最近的對話」才會附最近 16 則訊息
  - 同樣的錯誤一分鐘內只記一次；API 金鑰、登入碼等不會被記錄

### 自己寫的相遇情境
一般的戲劇衝突可以使用（英雄救美、被小混混找麻煩、打架受傷、車禍、生病住院）。只擋：性內容、未成年、真實人物或現有作品角色、血腥細節、奇幻／非人類設定。被擋下時會說明哪一點不行，並給一個改寫版本，可以一鍵套用或自己修改（原本寫的內容會保留）。

### 解決句點
- **回覆方向**：角色每次說完話，輸入框上方出現 3 個方向（例如「😂 吐槽他」「❓ 問後來呢」「🙋 說說我自己」），點了會幫你寫好一句放進輸入框，可以修改再送。可在「我 → 顯示回覆方向」關掉。
- **話題錦囊**（聊天室左下角 ✦）：「他帶我聊」、問他一件事、小遊戲（二選一、真心話、猜猜看、故事接龍）、一起做點什麼、分享照片。
- **角色主動帶話題**：對方連續回很短（嗯、哈哈、好）時，角色不再追問，改成分享一件事或提議小遊戲。
- 第一次相遇時角色會留一個好回答的小問題。

### 說話風格（後台可改）
角色依「年齡（20–24／25–29／30 以上）× 性別」套用一包說話風格：傳訊息的習慣加示範對話，再由個性原型微調。所有角色都避免單獨回「喔」「嗯」「哈哈」「笑死」這類容易句點人的字，並用台灣用語。後台「說話風格」分頁可以直接修改，立即生效。

### 不重複
- 他講過的自己的生活故事會被記下來，之後只能延續或說新進展，不會重講。
- 每聊 30 則會把較早的對話整理成摘要，讓他記得比最近 30 則更久以前的事。
- 新回覆和他最近說過的話太像時，會自動重寫一次，並在「系統紀錄」留一筆警告。

## 流行新品清單

陪吃飯推薦的「新品」只會從 `data/trends.json` 挑，避免模型編造。格式見 `trends.example.json`，每筆附官方來源網址與到期日；過期自動不用。改完不用重啟。

```bash
cp trends.example.json data/trends.json && nano data/trends.json
```

### 一起做點什麼與明信片

- 散步已移除。改成聊天室左下角的「話題錦囊」裡的「一起做點什麼」：一起看劇、陪你專心 25 分鐘（時間到他會來問進度）、睡前聊聊、一起吃飯。聊天中說好要一起看也會自動開始。
- 你傳很美的風景照時，他偶爾會做成明信片（一天最多一張），收進「我們的故事」。
- 他每週休假的下午會寄一張風景明信片給你。
- 角色都生活在現實的台灣：非人類、奇幻、異世界的情境會被婉拒。

### 上線狀態與回覆節奏

- 聊天室上方顯示他的狀態：🟢 上線中、🟡 上班中、⚪ 最後上線…、🌙 睡覺中，依他的作息自動切換。心情句改放在他的個人頁。
- 他在線上時：先「已讀」，1–4 秒後開始打字，每秒大約 5 個字，每則最多 8 秒，兩則之間停一下。
- 他在忙或睡覺時：真的晚點才回（上班中 1–8 分鐘、離線 1–3 分鐘、睡覺就等他起床，最晚早上 9 點），回的時候會說「剛剛在忙」「剛起床」，並推播通知。對方有危機訊號時一律馬上回。
- 測試者可以在「我 → 忙的時候晚點回」關掉延遲。

### 通知

- 第一次聊完會問要不要開通知；iPhone 會先教「加入主畫面」（iOS 只有從主畫面打開才收得到）。
- 同一個人連續傳好幾則，只會更新成一則「3 則新訊息」；App 圖示和「聊天」分頁會顯示未讀數字；你的勿擾時段通知不會響。
- 推播需要先在 `.env` 設定 VAPID 金鑰：`npm run vapid` 產生後貼進 `.env`，再 `pm2 restart companion`。

### 角色怎麼被形塑

不是訓練模型，而是每次對話都把角色設定寫進提示詞：

| 層 | 內容 | 什麼時候更新 |
|---|---|---|
| 核心人設 | 職業、原型、價值觀、口頭禪、生活中正在進行的事 | 建立時決定；官方角色可在後台「官方角色」調整 |
| 長出來的個性 | 幽默感、說話節奏 | 認識、朋友期每 15 則訊息，依對方的反應（回得長、笑了、延續話題／冷淡、明確不喜歡）整理；曖昧後鎖定 |
| 偏好 | 對方喜歡／不喜歡的說法（多一點、少一點） | 鎖定後仍每 30 則更新 |
| 相處習慣 | 對方明確要求的事（「別一直問我吃了沒」） | 說出口就記下，一直有效，優先於其他規則 |
| 記憶 | 喜好、作息、重要的事 | 每則訊息 |

每週到後台「數據」看本週摘要與「大家最常要求的相處習慣」，調整的是官方角色與整體規則，不改個別使用者的角色。

## 本機開發

```bash
npm install
npm run dev        # 不需要 OpenAI 金鑰，回覆是範例文字，可以走完所有流程
```
想看真實回覆：`OPENAI_API_KEY=sk-... STAGE_SPEED=4 node server/index.js`，`STAGE_SPEED` 讓關係推進加快，方便示範。

### 程式結構

```
server/
  index.js       API 路由、登入、上傳、靜態檔
  engine.js      對話編排層：組提示 → 呼叫模型 → 套用結果（記憶、關係、卡片、出遊…）
  prompt.js      角色規則、人設、當下情境、結構化輸出 schema
  scheduler.js   主動排程引擎（每分鐘）
  meet.js        相遇流程、情境結構化、角色分享
  memory.js      記憶挑選與權重
  ordering.js    下單轉接層、流行新品清單
  safety.js      危機偵測與求助資源
  characters.js  職業作息、角色原型、官方角色、情境
  admin.js       測試數據
public/          PWA 前端（無需打包）
```
